# Solving Quadratics Extra Practice

An interactive review sheet for solving quadratic equations. Open `index.html` in a browser (or turn on GitHub Pages for this repo) to use it.

**What students do on each question**
1. Choose the best method: GCF, factoring (a = 1), factoring (a ≠ 1), difference of squares, square root property, or quadratic formula.
2. Type the solutions. The page checks the answer and says if it is right. It also catches unrationalized denominators, unsimplified radicals, rounded decimals, a missing solution, and sign errors.

**Features**
- 17 starting questions: GCF, trinomials with and without a leading coefficient, difference of squares, square rooting, `(x + h)² + k` equations, rationalizing denominators, and the quadratic formula
- Calculator button: a floating, draggable calculator (√, powers, parentheses, Ans) students can open next to any question
- Help button with a method guide, typing tips, and step-by-step hints
- Whiteboard on the right side (pen colors, eraser, undo, clear), saved separately for each question
- Worked solution after each question
- A summary of what kinds of questions need more help, with buttons that add new, randomly generated questions of those types
- Progress is saved in the student's browser
